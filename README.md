## 📂 Featured Projects

### 🏥 [Hospital Readmissions Analysis](https://github.com/jillian-chamberlain/hospital-readmissions-analysis)
An end-to-end analysis of 100,000+ diabetic patient records from 130 US hospitals, using Python, SQL, and data visualization to identify characteristics associated with early hospital readmission. Built with pandas, SQLite, and matplotlib.

### 📊 [Minneapolis 311 Service Requests Dashboard](https://github.com/jillian-chamberlain/minneapolis-311-dashboard)
A two-page Power BI dashboard built on 81,000+ City of Minneapolis 311 requests. Cleaned and modeled the data in Power Query, wrote DAX measures (median time to close, % closed within 7 days), and found that Streets holds about 37% of the open backlog. Built with Power BI, Power Query, and DAX.

### 🎫 [Support Ticket Analysis](https://github.com/jillian-chamberlain/support-ticket-analysis)
A Python-based analysis of customer support ticket data exploring resolution efficiency, agent performance, and the relationship between ticket interactions and customer satisfaction. Built with pandas and matplotlib.

### 💳 [German Credit Analysis](https://github.com/jillian-chamberlain/german-credit-analysis)
Statistical analysis of credit risk data using R, exploring factors that influence creditworthiness.

### 🌸 [Flower Recognition AI](https://github.com/jillian-chamberlain/flower-recognition-ai)
A Python-based image classification model built to identify flower species using machine learning.
